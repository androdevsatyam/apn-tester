## 3. App Testing Detail & Daily Timer Screen

### App Header & Guidelines
- App Icon, Category, Package Name.
- Developer Instructions: e.g. "Test task creation, notification reminders, and dark mode toggle."

### Action Flow:
1. **[ 🔗 Open Play Store Opt-in Link ]** -> Opens official Google Play Web/App page.
2. User accepts beta invite and downloads app.
3. User returns to APN Tester -> Clicks **[ Launch App ]**.
4. In-app overlay / notification: **"Testing Timer Active: 2:00 remaining"**.
5. When 2 minutes is reached: Celebration chime + `+50 Points Earned for Today! 🎉`.

### Feedback Submitter:
- Star Rating (1 to 5 stars).
- Input: "Found any bugs or have UI suggestions?"
- Attachment: `[ 📷 Attach Screenshot ]`
- Button: **[ Submit Feedback (+100 Bonus Pts) ]**
